# tailwind-animate-css demo

Vite + Tailwind CSS v4 playground for this package.

## Run locally

From the repository root:

```sh
pnpm install
pnpm build
pnpm demo
```

Or from this folder (after building the parent package once):

```sh
pnpm install
pnpm dev
```

Use the **Network** URL from the terminal (not only `localhost`) when the editor runs on a remote host. In Cursor, forward port **5173** in the Ports panel.

Static build + preview (no HMR):

```sh
pnpm build
pnpm preview
```

Port **4173**.
